# Projeto-POO-Curicularizaçao
Projeto de Curicularização da materia de programação orientada objetos

Tema:Mapeamento e Cadastramento de Órgãos de Segurança do Alto Tiete

Descrição: O projeto tem como principal objetivo mapear e cadastrar órgãos de segurança como delegacias e corpos de bombeiros na área do alto tiete do estado de São Paulo, de forma a apresentar seus dados próprios de forma simples aos seus usuários. 

#Resumo de arquitetura e funcionamento

O projeto foi programado e testado na linguagem PHP, o banco de dados utilizado foi Mysql com o uso do usbwebserver,
porem pode ser utilizado usando xampp ou outro programa similar.
Ele usa o padrao MVC (Model View Controler) com CRUD (Create Read Update Delete).
