# Relatório de Especificações de Endpoints (Spring Boot MVC)

## I. Visão Geral da Aplicação

Esta aplicação utiliza Spring Boot com Spring MVC e Thymeleaf para implementar o CRUD (Create, Read, Update, Delete) nas entidades Delegacia, Policial, Bombeiro(Corpo de Bombeiros), Bombeiros. Os endpoints abaixo mapeiam as requisições HTTP para a lógica de negócio.

---

## II. Especificação de Endpoints (Rotas)

A base da aplicação é executada em `http://localhost:8081` (ou a porta configurada no `application.properties`).

### 1. Endpoints da Entidade: Delegacia (Prefixo: /delegacias)

| Método HTTP | Endpoint (URL) | Descrição | Parâmetros de URL | Tipo de Resposta | Controller Responsável |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `GET` | `/delegacias` | **Listar Todos.** Exibe a lista completa de todas as delegacias cadastradas. | Nenhum | Template HTML (`listaDelegacias.html`) | `DelegaciaController.listarDelegacias()` |
| `GET` | `/delegacias/novo` | **Exibir Formulário.** Exibe o formulário vazio para criação de uma nova delegacia. | Nenhum | Template HTML (`formDelegacia.html`) | `DelegaciaController.exibirFormulario()` |
| `POST` | `/delegacias` | **Salvar/Criar/Atualizar.** Recebe os dados do formulário para salvar uma nova delegacia ou atualizar uma existente (se o ID estiver presente). | Corpo: Objeto `Delegacia` (Formulário) | Redirecionamento (`redirect:/delegacias`) | `DelegaciaController.salvarDelegacia()` |
| `GET` | `/delegacias/editar/{id}` | **Exibir Formulário de Edição.** Busca uma delegacia pelo ID e preenche o formulário para edição. | `{id}`: ID da delegacia (Path Variable) | Template HTML (`formDelegacia.html`) | `DelegaciaController.editarDelegacia()` |
| `GET` | `/delegacias/deletar/{id}` | **Deletar.** Remove uma delegacia específica pelo ID. | `{id}`: ID da delegacia (Path Variable) | Redirecionamento (`redirect:/delegacias`) | `DelegaciaController.deletarDelegacia()` |

## III. Schemas de Dados (Modelos)

Esta seção descreve a estrutura das entidades persistidas pelo sistema.

### 1. Entidade `Delegacia` (Tabela: `delegacias`)

| Campo | Tipo no Banco | Requisitos (Java/JPA) | Descrição |
| :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | PK, Auto Gerado | Chave primária. |
| `nome` | `VARCHAR(100)` | `@NotBlank` | Nome da unidade policial. |
| `endereco` | `VARCHAR(255)` | `@NotBlank` | Endereço físico. |
| `telefone` | `VARCHAR(20)` | `@NotBlank` | Contato da unidade. |

### 2. Entidade `Policial` (Tabela: `policiais`)

| Campo | Tipo no Banco | Requisitos (Java/JPA) | Descrição |
| :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | PK, Auto Gerado | Chave primária. |
| `nome` | `VARCHAR(150)` | `@NotBlank` | Nome completo do policial. |
| **`patente`** | `VARCHAR(50)` | `@NotBlank` | Posto ou patente hierárquica. |
| `matricula` | `VARCHAR(...)` | `@NotBlank`, **Único** | Número de registro ou matrícula. |
| `delegacia_id` | `BIGINT` | FK, `@NotNull` | Chave estrangeira para a tabela `delegacias` (Relacionamento Many-to-One). |

### 3. Entidade `Bombeiro` (Tabela: `bombeiro`)

| Campo | Tipo no Banco | Requisitos (Java/JPA) | Descrição |
| :--- | :--- | :--- | :--- |

| `nome` | `VARCHAR(100)` | `@NotBlank` | Nome do corpo de bombeiros
| `endereco` | `VARCHAR(255)` | `@NotBlank` | Endereço físico. |
| `telefone` | `VARCHAR(20)` | `@NotBlank` | Contato da unidade. |

### 4. Entidade `Bombeiros` (Tabela: `bombeiros`)

| Campo | Tipo no Banco | Requisitos (Java/JPA) | Descrição |
